# 대전 UI 참고 자료와 적용

2026-11-14 조사. 게임 이름·로고·캐릭터·이미지를 앱 에셋으로 사용하지 않고, 공개된 화면의 정보 배치와 대전 흐름을 참고했습니다.

| 참고 | 확인한 화면 구성 | 이번 UI에 적용 |
|---|---|---|
| [Tetris Battle](https://tetris.wiki/Tetris_Battle_(Facebook)) · [대전 화면](https://2.bp.blogspot.com/-Qq4OMwFuby0/TokLB2i7GhI/AAAAAAAACDc/Zl6jvXnJP68/s1600/tettris-battle.png) | 내 판·상대판, HOLD/NEXT, KO와 보낸 줄 수, 큰 승패 표시 | 명확한 내 판/상대판 구분, 공격·KO·승패 피드백 |
| [한게임 테트리스 공개 기사](https://www.gamemeca.com/view.php?gid=74146) · [게임 화면](https://cdn.gamemeca.com/gmdata/0000/074/146/tetris_123.jpg) | 큰 내 판 주위 HOLD/NEXT, 여러 상대의 축소판, 순위, 우측 방 정보 | 큰 내 판, 최대 5개 상대 슬롯, 순위 배지와 참가자 라운지 |
| [넷마블 테트리스 회고 자료](https://witamy.kr/964) · [보존된 화면](https://t1.daumcdn.net/cfile/tistory/994F31425C7F4A2902) | 다인 상대 슬롯, 큰 내 판, NEXT, 우측 참가자/채팅, 시작 버튼 | 라운지 안 참가자·채팅·게임 시작, 방 목록에서 대전방 참가 |

넷마블 자료는 서비스 당시의 공식 문서가 아닌 보존 화면입니다. 화면에서 확인할 수 있는 정보 배치만 참고했습니다. 과거 서비스의 모든 규칙이나 기능을 재현하는 변경은 아닙니다.

## 구현

- 아케이드가 신규 사용자의 기본 테마. 저장된 기존 테마는 유지하며 업무 화면 전환 지원.
- 민트·청색 계열의 자체 디자인, 선명한 블록, 차별화된 내 판과 상대 카드.
- 서버 상태 기반 줄 삭제·공격·상쇄·KO 피드백(1.4초), 현재 공격 대상 강조.
- Canvas/DOM 렌더러의 셀 크기를 창 크기에 맞추고, 작은 창에서는 영역을 다음 줄로 배치.
- 방 찾기: 목록, 상태·인원·방장, 새 방 만들기, 코드 참가, 새로고침.
- 방 채팅: 최근 기록, 한글 IME 보호, 빈 메시지 방지, 이전 대화 읽기 시 스크롤 유지, 연결 상태와 접근성 지원.
- 게임 규칙, 서버 권위 판정, 바이너리 프로토콜은 유지.

## 확인

`cargo test -p bs-engine -p bs-server --locked`, WASM 대상 클라이언트 검사 및 Trunk 빌드.
실제 Chrome의 독립 세션 두 개를 이용한 `tools/smoke.py`로 방·채팅·테마 전환·봇·게임 시작을 검증합니다.
이전 `PERFORMANCE.md`의 수치는 이번 디자인의 측정치가 아닙니다.
